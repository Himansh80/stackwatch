# StackWatch — Pricing

**Last updated:** 2026-08-17

**Note:** Pricing is provisional. Tier 11 (Platform & Commerce) will finalize
Stripe + Razorpay wiring. Below is the published intent.

---

## Tier 1 — Personal (Free, forever)

- 1 server
- 5 API keys
- Email-only support
- Single-tenant, single-region
- AGPL-3.0 source available

**Best for:** Home users, monitoring your own infrastructure, no card required.

---

## Tier 2 — Pro

- $8 / server / month
- Unlimited API keys
- Email + chat support (24h SLA)
- Tier 1 (Proxmox full replacement)
- Tier 2 (TrueNAS SCALE full replacement)
- Tier 3 (browser SSH terminal)
- All future Tier 4-9 features

**Best for:** Homelab operators, MSPs running 5-100 servers.

---

## Tier 3 — Self-Hosted Business

- $500 / year (one license, all your servers)
- Everything in Pro
- Single sign-on (Tier 9)
- Audit logs (Tier 9)
- All Tier 4-9 features
- Source-available (cannot resell)

**Best for:** SMB IT teams, schools, enterprises that want Pro features
on their own hardware.

---

## Tier 4 — White-label OEM

- Custom pricing (contact sales)
- Everything in Self-Hosted Business
- Re-brand, re-sell (subject to contract)
- SLA + dedicated support

**Best for:** ISPs, MSPs, integrators selling under their own brand.

## Why pricing isn't tied to features per-user

Proxmox/TrueNAS/Cloud functions are **per-server**, not per-user. We charge
$8/scale to align cost with infrastructure, not seats — so adding a teammate
never costs more. This is unusual; competitors (Datadog, New Relic) bill per
host AND per-seat, leading to surprise overage.

---

## What we WILL NOT do

- **No charge for users.** Adding your engineer to a Pro account is free.
- **No charge for alerts.** Rule count, channel count, retention — all tied
  to plan tier, never user count.
- **No price increases for existing customers.** Whatever you pay for a
  server at signup, you keep paying.
